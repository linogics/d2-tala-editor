# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately through [GitHub security advisories](https://github.com/linogics/d2-tala-editor/security/advisories/new).

Include the version shown in the top bar of the editor, the browser, and steps or a D2 snippet that shows the problem. You should get an answer within a week.

## Scope

The editor is a static site without a backend. Relevant issues include script injection through D2 input or rendered SVG, and problems in the build or release pipeline. Bugs in D2 or TALA themselves should go to [d2lang/d2](https://github.com/d2lang/d2).

Only the latest release is supported.
